#Actividad 4 - Juego de tiro parabolico (Cannon)

# Proyecto basado en el juego de tiro parabolico de "turtle" en python en el cual se les apunta a pelotas que se estaran moviendo a lo largo de la pantalla.

#Cambios
-Aumento la velocidad del proyectil: se mueve mas rapido la bala y tiene una cadencia mayor.
-Aceleracion del objetivo: Las pelotas avanzan mas rapido.
-Duración del juego: El juego nunca termina, al momento en el que los balones alcanzan el otro extremo de la pantalla se reposicionan.
# Requisitos de aplicacion
-modulo: freegames

#Ejecucion:
bash
python3 cannon.py
